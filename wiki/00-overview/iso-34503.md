# ISO 34503：自动驾驶 ODD 分类标准

⚠️ ISO 34503 是付费标准，原文无法直接获取。本文内容综合自：Google Scholar 引用摘要（Bruce et al. 2024, Dierend et al. 2025, Betz et al. 2024）、Wikipedia ODD 词条、NHTSA 公开 AV 框架文件，以及 ODD 文档中。核心分类体系标注了来源，存疑处明确标注。

一句话总结：ISO 34503（2023）是专门针对自动驾驶系统 ODD 的国际分类标准，将 ODD 属性系统化组织为可量化、可测试的维度体系，是 SAE J3016 术语定义的精细化延伸，也是 BSI PAS 1883 的国际化升级版。

---

## 基本信息

- 标准：Road vehicles — Operational design domain (ODD) taxonomy for automated driving systems (ADS)
- 发布机构：ISO（International Organization for Standardization）/ TC22（道路车辆委员会）/ SC33（自动化驾驶分委员会）
- 标准号：ISO 34503
- 发布年份：2023 年
- 前身关系：在 BSI PAS 1883:2020（英国标准）基础上，以国际标准形式发布

---

## 核心问题

**SAE J3016 只定义了 ODD 是什么（"系统被设计为可安全运行的特定条件集合"），但没有告诉你 ODD 应该包含哪些具体属性**。这导致各公司、各监管机构定义的 ODD 格式不一致，无法直接比较和审查。

**ISO 34503 解决的问题**：

1. **属性体系不统一**：A 公司说"支持城市道路"，B 公司说"结构化道路最高 60 km/h"——无法判断覆盖是否等价
2. **可测试性不足**：抽象描述的 ODD（如"正常天气"）无法直接转化为测试用例
3. **跨标准对齐**：ISO 34503 与 SAE J3016、ISO 21448 SOTIF 的术语需要对齐

**ISO 34503 的定位**：不替代 SAE J3016，而是在 J3016 的 ODD 定义基础上，给出一套**完整的 ODD 属性分类体系**，让工程师可以用标准化词汇精确描述任何 ADS 的 ODD。

## ODD 属性分类体系

以下分类体系综合自多个公开来源（Wikipedia ODD 词条、NHTSA AV 4.0 框架、引用 ISO 34503 的学术论文）。ISO 34503 的精确条目需参考原文，以下为已知的主要维度框架：

### 1. 道路与基础设施（Road & Infrastructure）

**道路类型**：
- 高速公路（Highway / Motorway）
- 城市快速路（Urban expressway）
- 城市道路（Urban roads）
- 乡村道路（Rural roads）
- 停车场、私人道路

**几何特征**：
- 车道数量、车道宽度
- 道路曲率（直道 / 弯道半径）
- 坡度（平坦 / 坡道）
- 路面材质（沥青 / 混凝土 / 砾石）

**道路设施**：
- 交通信号灯（是否存在 / 运行状态）
- 交通标志（标准标志 / 临时标志 / 缺失或遮挡）
- 车道线（清晰 / 模糊 / 无标线）
- 停止线、人行横道

**特殊路段**：
- 施工区（Construction zones）
- 学校区域
- 隧道、桥梁
- 高速出入口、匝道

### 2. 环境条件（Environmental Conditions）

**天气**：
- 降水类型：无降水 / 小雨 / 大雨 / 暴雨 / 冰雹 / 小雪 / 大雪
- 降水量（mm/h 或 mm/h 区间）
- 雾：无 / 薄雾（能见度 > 200m）/ 浓雾（能见度 < 100m）
- 风速、沙尘

**光照**：
- 白天（日出后 / 日落前）
- 黄昏 / 黎明（过渡期光照）
- 夜间（有路灯 / 无路灯）
- 强逆光（低角度阳光）

**路面状态**：
- 干燥
- 潮湿（积水深度）
- 积雪（厚度）
- 结冰
- 落叶覆盖（影响摩擦系数）

### 3. 交通状况（Traffic Conditions）

**交通密度**：
- 稀疏（自由流）
- 正常
- 拥堵（密集 / 走走停停）

**道路参与者类型**：
- 机动车（小客车 / 货车 / 大型车 / 摩托车）
- 行人
- 自行车 / 电动自行车
- 特种车辆（急救车 / 警察 / 施工车）

**交通行为**：
- 是否包含变道、超车场景
- 是否包含无保护左转（Unprotected left turn）
- 是否包含与行人 / 自行车的交互

### 4. 速度范围（Speed）

- 最低速度（下限，含停车场景）
- 最高速度（上限）
- 速度限制类型（法定限速 / 场景限速）

示例：`0–65 km/h` 是典型城市 Robotaxi 的速度 ODD；`0–130 km/h` 是高速公路自动驾驶的速度 ODD。

### 5. 地理区域（Geographic Area）

- 特定城市 / 区域（如"旧金山市中心"）
- 是否需要预先 HD map 覆盖
- 地理坐标范围
- 海拔范围（高原低氧对传感器的影响）
- GPS 信号强度要求

### 6. 连接与通信（Connectivity）

- 是否需要 HD map 实时更新（地图新鲜度要求）
- V2X（车路协同）：是否需要路侧感知数据
- 远程监控（Teleoperation）：是否是运行的必要条件
- 网络连接：5G / 4G / 离线运行

> 注：对于 Waymo 等系统，HD map 更新是 ODD 的隐含条件；对于特斯拉 FSD，离线运行不依赖实时地图，这是 ODD 设计的根本差异之一。

### 7. 时间（Temporal）

- 运营时段（白天 / 夜间 / 全天候）
- 是否有节假日 / 特殊事件限制（大型活动期间）
- 地图有效期（HD map 上次更新距今时长）

## ISO 34503 的关键贡献

根据引用 ISO 34503 的学术论文（Bruce et al. 2024, Dierend et al. 2025），ISO 34503 相比早期 ODD 框架（BSI PAS 1883、各公司自定义）的主要进步：

1. **可测量性（Measurability）**：ISO 34503 对部分环境概念定义了可测量性（Dierend et al. 2025），即每个 ODD 属性需要对应可观测的物理量，而不只是定性描述
2. **语法与语义一致性**：ISO 34503 提供了 ODD 描述的语言语法框架，使不同系统的 ODD 可以用相同的结构表达（Bruce et al. 2024 进一步工作是验证这套语法的健壮性）
3. **国际统一**：BSI PAS 1883 是英国标准，ISO 34503 将其提升为国际标准，与其他 ISO 标准系列（21448 SOTIF、34501 测试场景词汇）对齐

## 与相关标准的关系

```
SAE J3016（2021）
  └─ 定义了 ODD 的概念 + 六个自动化等级
        │
        ▼
ISO 34503（2023）
  └─ 给出 ODD 的完整属性分类体系（J3016 的细化）
        │
        ├─ 与 ISO 21448 SOTIF：SOTIF 用于分析 ODD 内的未知不安全场景
        ├─ 与 ISO 34501：34501 是测试场景词汇，34503 是 ODD 本身的词汇
        └─ 前身：BSI PAS 1883:2020（英国标准，ISO 34503 的原型）
```

| 标准 | 回答的问题 | 层次 |
|---|---|---|
| SAE J3016 | ODD 是什么？自动化等级怎么分？ | 概念定义 |
| **ISO 34503** | ODD 包含哪些属性？每个属性怎么描述？ | **分类体系** |
| ISO 21448 SOTIF | ODD 内如何验证安全性？ | 验证方法 |
| ISO 34501 | 测试场景用什么词汇描述？ | 测试词汇 |
| ASAM OpenSCENARIO | 如何用代码/文件描述测试场景？ | 实现格式 |

## 局限性

- **可测量性仍不完整**：ISO 34503 只对"部分"环境概念定义了可测量性，不是全部属性都有量化标准（Dierend et al. 2025）
- **语法健壮性待验证**：学术界（Bruce et al. 2024）仍在研究 ISO 34503 ODD 语言的语法和语义是否足够严格，尤其在复合场景下
- **与实现工具链的距离**：ISO 34503 定义了"应该描述什么"，但如何将 ODD 转化为 ASAM OpenSCENARIO 格式的具体测试场景，需要额外的工程实践
- **付费门槛**：标准文档需要购买，限制了中小开发者的采用速度

---

## 现状与影响

一句话定性：**ISO 34503 是 2023 年发布的 ODD 分类国际标准，填补了 SAE J3016 "只定义概念、不给分类体系"的空白；学术界已开始围绕它构建更严格的形式化框架（2024–2025 多篇论文），工业界采用进度取决于各监管机构的法规引用速度——目前处于"已发布、正在渗透"的阶段。**

- **学术采用**：2024 年起出现多篇引用 ISO 34503 的论文（Bruce et al., Dierend et al., Betz et al.），研究重点是标准的形式化和可操作性
- **工业采用**：Tier-1 供应商（博世、大陆、安波福）和 OEM 在内部 ODD 文档中开始采用 ISO 34503 框架，但公开信息少
- **监管引用**：尚未见欧盟或美国法规正式引用 ISO 34503（SAE J3016 仍是监管文件中的主要引用），预计随 EU AV Regulation 推进将逐步纳入
- **不会取代 SAE J3016**：两者互补，J3016 定义等级和概念，34503 提供属性分类
